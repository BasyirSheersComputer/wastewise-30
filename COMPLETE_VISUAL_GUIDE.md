## 🎨 Color Usage Examples

### Status Colors
```
✓ Good/Success    → Green (#2D9F4B)
⚠ Warning/Low     → Yellow (#F59E0B)
❌ Error/Critical → Red (error color)
ℹ Info/Neutral   → Teal (#00A7A7)
```

### Trend Indicators
```
↑ Green  → Good increase (savings, efficiency)
↓ Green  → Good decrease (waste, costs)
↑ Red    → Bad increase (waste, costs)
↓ Red    → Bad decrease (savings, efficiency)
```

### Priority Badges
```
[HIGH]   → Red badge
[MEDIUM] → Yellow badge
[LOW]    → Blue badge
```
