# LinkedIn Outreach Quick Reference Guide
## WasteWise AI - Malaysian F&B Chains

**Quick Access:** Daily, weekly, and monthly action items for executing the LinkedIn outreach strategy.

---

## Daily Actions (15-30 minutes)

### Morning Routine (9:00 AM)
- [ ] Check LinkedIn notifications (10 min)
- [ ] Respond to messages/comments (5 min)
- [ ] Send 10-15 connection requests (10 min)
- [ ] Engage with 5-10 posts (comment/like) (5 min)

### Connection Request Template (Quick Copy) - BETA PILOT
```
Hi [Name], I'm launching WasteWise AI - AI forecasting for Malaysian F&B chains. Looking for 3-5 pilot partners. Benefits: 60-day free trial + lifetime 50% off. [Company] operates [X] locations - interested in being first? Open to connecting?
```

### Afternoon Follow-Up (2:00 PM)
- [ ] Follow up on pending connection requests (5 min)
- [ ] Send follow-up messages to accepted connections (10 min)
- [ ] Schedule discovery calls (5 min)

### Follow-Up Template (Quick Copy) - BETA PILOT
```
Hi [Name], Thanks for connecting! We're launching a beta pilot - 60-day free trial + lifetime 50% off for first 5 partners. Since [Company] operates [X] locations, thought you might be interested. Want to learn more?
```

## Script Library (Quick Access)

### Connection Request
```
Hi [Name], I help Malaysian F&B chains reduce waste by 35-45% with AI forecasting. Since [Company] operates [X] locations, thought you might find this relevant. Open to connecting?
```

### After Connection Acceptance
```
Hi [Name], Thanks for connecting! I've created a quick guide: "5 Ways Malaysian F&B Chains Reduce Waste Costs" - would you like me to send it?
```

### Beta Pilot Invitation (Quick Copy)
```
Hi [Name], We're launching a beta pilot program - looking for 3-5 F&B chains to partner with. Benefits: 60-day free trial + lifetime 50% off + shape product development. Since [Company] fits our profile, interested in a quick 15-min call?
```

### Follow-Up (No Response)
```
Hi [Name], I know you're busy. If waste management isn't a priority right now, no problem. But if you'd like to explore how AI forecasting could help [Company], I'm here. Just reply and I'll respond right away.
```

## Objection Handling (Quick Reference)

**"We're not interested"**
→ "No problem. If waste costs become a priority, I'm here. Mind if I check back in 3 months?"

**"Too expensive"**
→ "I understand. What would need to happen for this to be a no-brainer? Many chains see RM 100K+ monthly savings - that's a 10-20x ROI."

**"We're not ready"**
→ "What would need to change for you to be ready? We can start with a 30-day trial - no commitment."

**"Send me more info"**
→ "Happy to! I'll send over our case study and ROI calculator. Would you be open to a quick 15-min call after you review?"
