## 📋 Document Naming Conventions

### Standard Format
`CATEGORY_DESCRIPTION.md`

**Examples:**
- `LINKEDIN_OUTREACH_STRATEGY.md` - Marketing strategy
- `PRODUCT_ALIGNMENT_AND_ICP_SEGMENTATION.md` - Product strategy
- `WASTEWISE_PRODUCT_PROPOSAL.md` - Business proposal

### Subdirectory Files
`SUBDIRECTORY/FILE_NAME.md`

**Examples:**
- `architecture/WASTEWISE_PRODUCT_REQUIREMENTS_DOCUMENT.md`
- `deployment/QUICK_DEPLOYMENT.md`
- `security/DEPLOYMENT_SECRETS_GUIDE.md`

## 📝 Metadata Template

For new documents, use this template:

```markdown
# Document Title
## Subtitle/Description

**Document Type:** [Strategy/Guide/Specification/Summary]  
**Version:** 1.0  
**Date:** [Month Year]  
**Purpose:** [One-line purpose]

**Related Documents:**
- [Related Doc 1](path/to/doc1.md) - Description
- [Related Doc 2](path/to/doc2.md) - Description

---
```
